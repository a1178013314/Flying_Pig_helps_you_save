# 术语表

本仓库的通用语言。下游（spec、代码、文案）一律复用这里的意思，不另起同义词。

| 术语                 | 意思                                                                                                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 飞猪帮你省           | 本产品名。旅游智能体，围绕省心 / 省钱 / 省时间三件事。                                                                                                                       |
| 入口页               | 复刻飞猪 App 首页的移动首页（视觉事实源：`docs/入口页面，这个要原样实现.jpg`）。                                                                                             |
| 三段页               | 承载三个功能的功能页形态：一屏只做一件事，三段之间切换（已选方案：`docs/原型/功能页-三段页（已选）.png`）。                                                                  |
| 省心 / 省钱 / 省时间 | 三个功能，各占三段页的一段。省心 = 行程中断后重规划；省钱 = 盯指定航线与班次、按定制时机提示；省时间 = 算未来 5 天哪天走更便宜。                                             |
| 智能体运行时         | opencode CLI。所有数据查询与判断的唯一执行者，由它自己决定调用 flyai 的顺序与次数。模型 `bailian/qwen3.8-flash`（参赛要求），走百炼兼容端点，key 从 `BAILIAN_API_KEY` 注入。 |
| flyai                | 飞猪官方 skill / CLI（`@fly-ai/flyai-cli`），查真实机票、火车、酒店、门票价库。机票报价无需 key 即精确；其余品类需 key 才精确。                                              |
| 体验模式             | 未注入 `FLYAI_API_KEY` 时 flyai 的状态：非机票价格被打码（`¥2xx`）且结果受限；界面必须显式标注，不得当作精确价计算。                                                         |
| 执行目录             | 每次任务给 agent 的一次性沙箱 `/tmp/flypig-agent/<jobId>/`：含本次 `opencode.json`、`input.json`、flyai skill 副本、`raw/` 与产物文件。跑完即删，失败保留 7 天供排查。       |
| 任务输入             | 执行目录里的 `input.json`：`{type, task, previous}`。agent 的上下文只从这里来（航线、目标价、被打断的行程、上一轮快照），不开多轮会话、不靠对话记忆。                        |
| 产物                 | agent 交出的文件：`offers.json`（列班次）/ `dataset.json`（快照）/ `plan.json`（替代行程）；另有 `raw/` 存每次 flyai 调用的原始 stdout。                                     |
| 闸门                 | 产物落库前的三道校验：结构（守卫）/ 完整（5 天齐全）/ 有据（每个价格能在 `raw/` 里找到、链接域名为 `router.feizhu.com`）。任一道不过即失败。                                 |
| offer                | flyai 行程经归一化后的最小集合（班号 / 航司 / 起降站与时刻 / 时长 / 价格 / 预订链接）；前后端只认这个形状。                                                                  |
| 数据快照             | 一份缓存数据（meta / watch / interruption），省钱与省心两段共用。刷新时整份原子替换，不得分段各存一份。                                                                      |
| 刷新任务             | 一次 opencode 执行，分 discover（列班次）/ refresh（重写快照）/ replan（给替代行程）。状态 queued / running / done / failed，存单实例内存；同类型在跑时复用同一 jobId。      |
| 重规划               | 省心段把「被打断的行程 + 用户描述的情况」交给 agent，由它查替代方案并排序解释，返回 1–3 条；不落库。                                                                         |
| 种子快照             | 入库的初始数据，断网或 agent 失败时兜底；使用时 `source=seed`，界面标「示例数据」。                                                                                          |
| 示例数据 · 一键更新  | 刷新动作的固定文案。只有退回种子时才是「示例」，其余时候数据来自 flyai 实查。                                                                                                |
| 目标价               | 省钱段用户设定的价格线；曲线与目标虚线的几何距离就是「还差多少」。                                                                                                           |
| 方向契约             | `.impeccable/surfaces/*.md` 里锁定的页面方向（论点 / 视觉世界 / 叙事 / 首屏 / 形式 / 签名 / 完成标准 + 方案图引用）。                                                        |
| 探针                 | `GET /api/health`，只证明进程存活，不接任何存储。                                                                                                                            |
| traceId              | 一条请求的追踪号。进：读 `x-trace-id`，缺则生成；出：响应头回写；日志经 mixin 自动携带。                                                                                     |
