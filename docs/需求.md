# 一、这是个旅游智能体的项目 名字叫飞猪帮你省

功能有3个
1、 省心。误接驳 各种意外情况导致形成中断可以一键规划
    可能需要用户输入 比如是自身情况导致的 比如带娃出游生病，临时有事等等需要用户输入，一些信息

2、 省钱  监听指定航班 解析用户输入 可个定制时间推送
    需要用户输入航班号

3、 省时间 用户有了确定目的地，帮用户算出未来5天哪天走更便宜
    需要用户输入开始城市和目的地

# 二、数据提供
    没有用户数据 需要你来编 而且要支持 一键更新，使用智能体编
