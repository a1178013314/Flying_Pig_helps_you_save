# 初始架构设计（飞猪帮你省）

- 日期：2026-11-04
- 范围：只做骨架，不含业务。三个功能页、入口页复刻、数据生成与 opencode 接入均不在本次。
- 依据：`.qoder/spec/initial-framework-scaffolding-spec.md`（下称 spec），本次对其 4 处偏移见 §7。

## 1. 结构

```
apps/admin/                 @flypig/admin      NestJS 12 + TypeORM 1 + SQLite
apps/web/                   @flypig/web        Vite 8 + React 19 + RR8 + Tailwind 4
packages/logger/            @flypig/logger     pino 10 薄封装，tsup 双产物
packages/shared/            @flypig/shared     前后端同源类型，tsup 双产物
packages/typescript-config/                    base.json
biome.json  pnpm-workspace.yaml  package.json  .env.example
```

命名：token key 若将来需要为 `fp_token`，数据库 `data/flypig.sqlite`，日志 `logs/admin.log`。

## 2. 工具链

- `packageManager: pnpm@11.13.0`（本机实测版本），`engines.node >= 22.12`；
- 根脚本 `build` / `typecheck` / `test` 走 `pnpm -r`，`lint` 走 `biome check .`；
- `dev:admin` 先构建 logger 再 `nest start --watch`；`dev:web` 起 vite；`dev` 用 `pnpm -r --parallel --filter` 同时起两个；
- Biome 全仓生效（含 admin），无历史例外；
- Vitest 全仓一套；admin 用 `unplugin-swc` 保 decorator metadata；
- 端口：admin 3001（`PORT` 可覆盖），web 5173。

## 3. 后端（apps/admin）

- `main.ts`：加载 `.env`、解析 `PORT`（非法即 `exit(1)`）、调 `bootstrapApp()`、listen；
- `app.bootstrap.ts`：`bootstrapApp()` 装配前缀 `api`、`ValidationPipe`（whitelist + transform）、`HttpExceptionFilter`、`TraceMiddleware`、Swagger `/api/docs`、`enableShutdownHooks()`。main 与 e2e 共用；
- 配置：Joi 校验，`NODE_ENV` 必填（枚举），`PORT` / `DB_PATH` / `LOG_FILE_ENABLED` 有默认值；业务读 `config.get("<namespace>.<key>")`；
- 数据库：`TypeOrmModule.forRootAsync` + `better-sqlite3` + `autoLoadEntities`，`synchronize: true`（骨架期，代码留 shortcut 注释）；
- 探针：`GET /api/health` → `{ status, timestamp, uptime }`，不接存储；
- traceId：中间件读 `x-trace-id`，缺失生成 UUID，`runWithTrace` 建作用域，**`next()` 之前写响应头**；
- 异常：`@Catch(HttpException)` → `{ statusCode, message, error, path, timestamp }`，同时记一条结构化 error；
- 日志：`AppLoggerService` 替换 Nest logger，pino 输出 JSONL 到 stdout + `logs/admin.log`，mixin 注入 traceId，写文件失败只告警不抛错。

## 4. 前端（apps/web）

- 路由：`"/"` 一屏连通验证页，`"*"` NotFound；无登录、无 AuthProvider、无 401 跳转；
- `apiFetch`：补 `/api` 前缀、按需 `content-type`、读 `x-trace-id` 归一 `ApiError { message, traceId, status }`、错误消息取 `body.message`（数组 join）、空 body 返回 `undefined`、网络失败提示「后端服务不可达」；
- 令牌：`@theme` 落品牌橙 `#FF5B23`、灰底 `#F2F3F5`、深色 `#221A17`、圆角 12/16、价格 34px（出处：`.impeccable/surfaces/web-src-routes-save.md` OWN-WORLD）；
- 移动优先：`max-w-[480px] mx-auto`、`min-h-dvh`、viewport meta 锁定。

## 5. 测试

- logger：缺 `service` 抛错、trace 上下文沿用；
- shared：分页纯函数；
- admin e2e：health 200、traceId 响应头与日志同值、404 结构、SQLite 临时库写读；
- web：apiFetch 的路径前缀、错误归一、空 body、网络失败。
